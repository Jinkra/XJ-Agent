# 激活与发布保护

小金同学提供单文件 Windows 安装包，按版本离线激活。当前固定激活码适合公众号分发。共享码可以被转发，公开源码也允许第三方自行构建修改版。以下措施保护官方发行版，并提高篡改与批量试码的成本。

## 当前发行版

- 主进程校验激活码，使用 scrypt 派生摘要。连续输错五次会暂停 30 秒，尝试记录和激活凭据由 Windows 用户密钥保护。升级版本后需要重新激活。
- 发行版启用 Electron ASAR 完整性校验，并关闭打包版开发者工具及 Node 调试入口。系统操作仅接受已激活的应用主页面发出的请求。
- 每个新版的更新清单由发布密钥签名。客户端验证清单签名和 EXE 的 SHA-256 后执行替换。发布私钥保存在 GitHub Actions Secrets（`XJ_AGENT_UPDATE_SIGNING_KEY`），与小金工具箱的密钥相互独立。

## 强化方案

如需限制激活码转发，可将共享码升级为按版本、按设备签发的许可证。激活页生成含版本号和设备标识摘要的申请码，公众号后台或管理员签发工具生成 Ed25519 签名许可证。签发私钥只放在签发端，客户端用内置公钥验证版本、设备绑定和有效期。用户拿到许可证后仍能离线使用。

许可证签名密钥应独立于更新签名密钥。签发端可以限制每个用户的设备数量并记录撤销状态，客户端则通过许可证到期或下次版本激活获取更新后的授权状态。对外发布时也可以给 Windows EXE 加 Authenticode 签名，方便用户核对发行者。
